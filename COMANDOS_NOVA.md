# NovaMind v5 — Command Engine

NovaMind v5 convierte una orden en un flujo de trabajo. El comando maestro es `/hazlo`.

## Prueba rápida

Escribe:

`/hazlo Necesito aprender Python desde cero en 7 días. Hazme un plan práctico, ejercicios y una forma de comprobar si aprendí.`

NovaMind: planifica → ejecuta pasos → verifica → entrega una respuesta final.

## Comandos principales

- `/hazlo` — motor maestro de ejecución.
- `/resuelve` — problemas complejos.
- `/investiga` — investigación con búsqueda web.
- `/crea` — convertir una idea en un entregable.
- `/anuncio` — campaña publicitaria.
- `/video` — pipeline audiovisual.
- `/datos` — análisis de datos.
- `/codigo` — software, pruebas y correcciones.
- `/automatiza` — diseño de automatizaciones.
- `/aprende` — aprendizaje guiado.
- `/explica` — explicación adaptada al nivel.
- `/compara` — comparación estructurada.
- `/detecta` — encontrar problemas y anomalías.
- `/plan` — plan ejecutable.
- `/equipo` — dividir trabajo por roles.
- `/verifica` — auditoría y control de calidad.
- `/continua` — continuar un proyecto.
- `/pack` — paquete de contenidos.
- `/modoexperto` — mayor profundidad técnica.
- `/modoexpress` — respuesta rápida y directa.

También conserva `/cinema`, `/storyboard`, `/director`, `/promptlab`, `/remix`, `/memory`, `/research`, `/code` y `/voice`.

## Importante

El motor ejecuta lo que las herramientas conectadas permiten. No afirma haber enviado correos, publicado contenido, comprado, modificado cuentas o realizado acciones externas si no existe una integración autorizada para hacerlo.

La función `/cinema` crea movimiento local sobre una imagen y exporta MP4; no es vídeo generativo.
